# Основные эндпоинты NetBird API (`/api`)

- **Peers (узлы):** `GET /peers`, `GET /peers/{id}`, `PUT /peers/{id}`, `DELETE /peers/{id}`
- **Groups (группы):** `GET /groups`, `POST /groups`, `PUT /groups/{id}`, `DELETE /groups/{id}`
- **Policies (ACL-правила):** `GET /policies`, `POST /policies`, `PUT /policies/{id}`, `DELETE /policies/{id}`
- **Routes (сетевые маршруты):** `GET /routes`, `POST /routes`, `PUT /routes/{id}`, `DELETE /routes/{id}`
- **Setup Keys:** `GET /setup-keys`, `POST /setup-keys`, `PUT /setup-keys/{id}`, `DELETE /setup-keys/{id}`
- **DNS Nameservers:** `GET /dns/nameservers`, `POST /dns/nameservers`, `PUT /dns/nameservers/{id}`, `DELETE /dns/nameservers/{id}`
- **Users / Tokens:** `GET /users`, `GET /users/{id}/tokens`
